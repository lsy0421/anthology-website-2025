# anthology-website-2025

## About this project

A multi-page static website built in 2025 for an anthology publication project.
I was the sole developer and also handled UI and interaction design.

- **Role:** Solo developer · UI / interaction design
- **Stack:** HTML, CSS, JavaScript (no framework, no build step)
- **Highlights:**
  - 8 hand-built pages: landing, intro, artwork gallery, fiction directory, video and concept pages
  - Responsive layouts written with CSS media queries
  - CSS transitions / keyframe animations plus Animate.css for page entrance effects
  - Vanilla JavaScript click interactions on the intro page
  - Concept video hosted via GitHub Releases and embedded with HTML5 video

> **Status:** Archived. The site is no longer online; this repository is kept for code reference.
> All artwork and written content belong to their original creators.
